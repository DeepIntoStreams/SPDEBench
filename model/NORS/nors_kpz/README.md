# NORS for KPZ

This package implements a one-dimensional NORS baseline for the renormalized
KPZ datasets generated by `data_gen/examples/gen_KPZ.py`.

## Features

KPZ contains the derivative nonlinearity
`lambda * ((partial_x u)^2 - C)`. Its features therefore differ from the
non-derivative Phi41 and two-dimensional Phi42 features:

1. `I[xi]`
2. `I_c[u_0]`
3. `I[I[xi]]`
4. `I[I_c[u_0]]`
5. `I[(D I[xi])^2-C]`
6. `I[(D I[xi])(D I_c[u_0])]`
7. `I[(D I_c[u_0])^2]`

The generator passes its truncation to `SPDE.Parabolic_reno` as `C`; therefore
`--renorm-constant` must match the dataset truncation. `W` is cumulative and
mollified, so the feature builder uses
`xi = noise_scale * diff(W) / dt`.

The generated grid includes both periodic endpoints. The default
`--spatial-points 128` drops the duplicate final point, matching the existing
FNO/NSPDE spatial convention.

## Training

From the repository root:

```bash
python -m model.NORS.nors_kpz.train \
  --data-path "/workspace/results/KPZ+/KPZ+renosigma01_xi_lam005_trc128_1200.mat" \
  --output-dir "/workspace/result/NORS_KPZ/seed_3407" \
  --checkpoint-name "NORS_KPZ_sigma01_lam005_trc128_best_val.pt" \
  --max-time 51 \
  --sub-t 1 \
  --sub-x 1 \
  --spatial-points 128 \
  --diffusion 1.0 \
  --noise-scale 0.1 \
  --renorm-constant 128 \
  --feature-batch-size 64 \
  --ntrain 840 \
  --nval 180 \
  --ntest 180 \
  --batch-size 10 \
  --epochs 1000 \
  --learning-rate 0.001 \
  --weight-decay 0.0001 \
  --modes-x 16 \
  --modes-t 16 \
  --width 32 \
  --depth 4 \
  --time-padding 6 \
  --scheduler-patience 50 \
  --scheduler-factor 0.1 \
  --early-stopping 80 \
  --delta 0.0002 \
  --print-every 20 \
  --seed 3407 \
  --device cuda
```

The first run writes a resumable NumPy feature cache. Early stopping always
saves the true lowest-validation checkpoint; `delta` controls only the patience
counter.

## Independent evaluation

```bash
python -m model.NORS.nors_kpz.eval \
  --checkpoint "/workspace/result/NORS_KPZ/seed_3407/NORS_KPZ_sigma01_lam005_trc128_best_val.pt" \
  --output-dir "/workspace/result/NORS_KPZ/seed_3407/evaluation" \
  --eval-data-paths \
    "/path/to/KPZ_test_seed10001_180.mat" \
    "/path/to/KPZ_test_seed10002_180.mat" \
    "/path/to/KPZ_test_seed10003_180.mat" \
    "/path/to/KPZ_test_seed10004_180.mat" \
    "/path/to/KPZ_test_seed10005_180.mat" \
  --noise-scale 0.1 \
  --renorm-constant 128 \
  --skip-save-predictions \
  --delete-feature-cache-after-eval
```

The evaluator reports Rel. L2, W1,2, Sig-W1, AutoCorr, CrossCorr, and model
inference time per sample.

This is an equation-informed KPZ extension of NORS. The upstream NORS clone
does not contain a canonical KPZ implementation, so results should be described
as a KPZ-specific derivative-feature NORS baseline.
